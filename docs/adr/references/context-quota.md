# Make Your LLM Fully Utilize the Context (Context Quota)

- **Link:** https://arxiv.org/abs/2404.16811
- **Kind:** Paper
- **Date:** 2024-04
- **Relates to:** ADR-0002b §4 (zones), ADR-0002h

Trains models to allocate a finite attention budget across context segments — a learned interior analogue of our exterior zonal risk structure. Evidence that position and allocation discipline inside the window materially changes retrieval behavior; useful background for choosing zone boundaries and for the 'why not just add more context' argument.
